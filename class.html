A privacy-friendly overview of pupils' self-assessed AI-literacy performance tasks. The Removes course stores work on each pupil's own device (no login, works offline), so pupils share a short code from their Portfolio → "Share with teacher". Paste those codes below — one per line — to build a class grid. Nothing is uploaded; this page runs entirely in your browser.

Two ways to add pupils: paste their codes (levels only), or import their exported work files (levels + the actual written responses, which appear below the grid for moderation).
